Privacy Policy

Kindle Dash · last updated 4 November 2026

Who uses Kindle Dash

Kindle Dash is a personal project used only by its owner, to show their own calendars and tasks on their own Kindle. It is not offered to the public.

What data it accesses

With the owner's permission, Kindle Dash uses Google's APIs to read the owner's Google Calendar events and Google Tasks, and, when the owner asks it to on the touchscreen, to mark tasks as done and delete tasks or calendar events.

Where the data goes

The data is processed only by a server running on the owner's own computer, which draws an image for the owner's Kindle on their home network. It is not sent to any other server, is not shared with or sold to anyone, and is not used for advertising or for training any model. Google sign-in tokens are stored only on the owner's computer. Weather comes from Open-Meteo, which receives only a location, never Google data.

Retention

Calendar and task data is held in memory while the server runs and is refreshed every few minutes; it is not stored long term.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions, which stops Kindle Dash reading any further data.

Google API Services User Data Policy

Kindle Dash's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
